# Учёт кредитов и подписок

Приложение для контроля кредитов, платных подписок и планирования досрочного погашения.

## Возможности

- Учёт кредитов: сумма, остаток долга, ставка, мин. платёж, фактически оплачено
- Учёт платных подписок с категориями (стриминг, софт, облако и др.)
- Напоминания за 3 дня до списания (браузерные уведомления)
- Аналитика: графики, рекомендации по погашению (методы «Лавина» и «Снежный ком»)
- Калькулятор досрочного погашения — показывает экономию времени и денег
- Экспорт и импорт данных для синхронизации между устройствами

## Как установить

1. Распакуйте ZIP-архив в любую папку на компьютере
2. По желанию переименуйте `index.html` в удобное вам название, например — `Кредиты.html`
3. Откройте файл в браузере (Chrome, Firefox, Edge, Яндекс.Браузер)
4. Всё, приложение работает — никаких установок, серверов, регистраций

При первом запуске браузер запросит разрешение на уведомления — **разрешите**, чтобы получать напоминания о списаниях.

## Как перенести на телефон

1. На компьютере нажмите кнопку **Экспорт** (в шапке приложения) — сохранится JSON-файл
2. Отправьте этот файл на телефон (через Telegram, WhatsApp, почту, облако)
3. На телефоне откройте `index.html` в браузере
4. Нажмите **Импорт** и выберите сохранённый файл

Так же — в обратную сторону: Экспорт на телефоне → Импорт на компьютере.

Данные хранятся только в вашем браузере (localStorage) и никуда не передаются.

## Как обновлять данные

Достаточно вносить платежи через кнопку **«Внести платёж»** в карточке кредита. Остаток долга пересчитывается автоматически.
